# Version 0.8.0

Released: 2026-05-03

Commit range: `498bd5e..af883d3`

## Major changes

- Added an editor-hosted session view: sessions can now live in a regular editor tab via a new `AgentCliSessionFileEditorProvider`. Right-click any active or historical session in the sidebar and pick **Open in Code Editor** to move it out of the tool window, and use the **Return to plugin view** link at the top of the tab to move it back. Each transition is a clean close + resume, so the sidebar's active-sessions list stays consistent regardless of where the session is hosted, and closing the editor tab closes the session.
- Added an **Always open new sessions in code editor** setting. When enabled, new sessions open directly as editor tabs instead of in the tool window; per-session **Open in Code Editor** still works regardless of the setting.
- Added a red overlay dot on the sidebar collapse/expand toggle button so attention-needed state stays visible when the session list is collapsed. The toolbar refreshes on `SESSION_ATTENTION_TOPIC` events.

- None.
