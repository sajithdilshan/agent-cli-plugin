# Version 1.1.0

Released: 2026-10-24

Commit range: `ca2d1e8..HEAD`

## Major changes

- Added an opt-in Claude Code mod (`agent-cli-links`), enabled under *Settings → Tools → Agent CLI → Claude Code Mods* (shown only while Claude is enabled). It adds an `agentcli://open` link under each tool call that touches a file; clicking it opens the file in the IDE at the changed line. Links are limited to the session's working directory and the project, and the file is refreshed from disk before opening so the agent's latest edits are shown.
- Editor tabs hosting a session now show the session name in the tab tooltip instead of the internal `agent-cli-session://` URL.
- Updated the bundled xterm.js to `6.1.0-beta.315` with matching addons (fit, unicode11, web-links).

## Major fixes

- Replaced the remaining deprecated IntelliJ Platform API usages reported by the Marketplace verifier (`FileEditorManager.openFile(VirtualFile, boolean)` and `EditorTabTitleProvider.getEditorTabTooltipText`) with APIs that are stable across builds 261–263.

## Tooling

- Updated Gradle to 9.8.0, Kotlin to 2.4.20, the IntelliJ Platform Gradle plugin to 2.19.0, ktlint Gradle plugin to 14.2.0, and JUnit to 6.1.3; reformatted sources for ktlint 14.
