# Version 0.9.0

Released: 2026-06-12

Commit range: `aed9190..8334e66`

## Major changes

- Added a new **Sandbox** agent type that runs any underlying agent CLI through a generic wrapper command (e.g. a containerized, sandboxed runner like `claude-crate`). Configure it in **Settings → Tools → Agent CLI → Sandbox** with three fields:
    - **Command** — the wrapper command, with `{dir}` marking where the (quoted) project path is inserted; if `{dir}` is absent the path is appended.
    - **History dir** — the base directory where the sandboxed agent writes history (replaces the underlying agent's default home, e.g. `~/.claude-crate` in place of `~/.claude`).
    - **Runs as** — which agent actually runs inside the sandbox; selects the history parser, project-path encoding, and resume syntax.
- Added `AgentCommandBuilder`, centralizing launch/resume command construction. Resume reuses the underlying agent's syntax with the project path injected (Codex uses `resume <id>`, others `--resume <id>`).
- Added `SandboxHistoryReader`, which delegates to the underlying agent's history reader rooted at the configured sandbox history directory.
- Sandbox sessions are visually distinguished by a green gradient bar across the top of the terminal and a matching gradient label in the history list.
