# Version 0.2.0

Released: 2026-04-06

Commit range: `9063ba8..93f3ebd`

## Major changes

- Repositioned the plugin from a Claude-only integration to the broader `Agent CLI` plugin.
- Added Cursor support with a dedicated history reader and multi-agent session model.
- Added Gemini support and exposed it in plugin settings and the session UI.
- Renamed packages, UI classes, icons, and plugin metadata to match the new Agent CLI branding.
- Updated the Gradle and IntelliJ platform configuration for newer build tooling and compatibility.

## Major fixes

- Improved the sidebar UI and general tool window behavior.
- Fixed multiple terminal and rendering issues during early plugin stabilization.
- Added bundled font assets and follow-up font rendering fixes.
