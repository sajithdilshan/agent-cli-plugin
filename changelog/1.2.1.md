## Major fixes

- Fixed a crash (`NoClassDefFoundError: com/pty4j/PtyProcessBuilder`) when starting a session on IntelliJ Platform 2026.3+ (build 263). pty4j moved out of the core classpath into a separate bundled plugin (`com.intellij.modules.pty4j`, "Pseudo Terminal (PTY4J)"). The plugin now declares it as an optional `<depends>` (with an empty `agentcli-pty4j.xml` config file), so its classes are visible on 2026.3+ while 2026.1/2026.2, where pty4j is still in the core classpath, keep working.
