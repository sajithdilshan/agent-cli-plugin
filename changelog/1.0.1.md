# Version 1.0.1

Released: 2026-08-19

Commit range: `6a20778..HEAD`

## Major changes

- None — patch release.

## Major fixes

- Fixed a crash (`PluginException: Cannot create editor by provider ... / NullPointerException: Cannot read field "isNull" because "robj" is null`) when opening a session in an editor tab. Recent IDEs run JCEF as a separate `cef_server` process; if that process dies during a long-running IDE session, `JBCefApp.isSupported()` still reports success but the first `JBCefJSQuery.create()` fails inside JCEF. The failure aborted editor creation and left a session registered in the sidebar with no owner, plus leaked native browser objects.
- Terminal creation now fails cleanly: `CefTerminalPanel` builds the browser and its four JS bridges through a factory that disposes partial results and reports a `TerminalUnavailableException`. Editor-hosted sessions show "Restart the IDE and try again" inside the tab, tool-window sessions show an error balloon (new `Agent CLI` notification group), and the pending session is removed instead of lingering as a dead row.

## Tooling

- Added a GitHub Actions workflow that builds, signs, publishes to the JetBrains Marketplace, and cuts a `v<version>` GitHub release on every push to `main` that changes `pluginVersion`; documented the versioning and channel rules in `RELEASE_GUIDELINE.md`.
- Replaced deprecated IntelliJ Platform API usages and enabled the corresponding compiler checks in `build.gradle.kts`.
