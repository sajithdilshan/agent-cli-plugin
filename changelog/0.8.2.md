# Version 0.8.2

Released: 2026-05-16

Commit range: `ab02adc..b11ed5b`

## Major changes

- None.

## Major fixes

- Fixed IDE title bar showing the internal URI path instead of the session display name when a session is hosted in an editor tab (`getPresentableUrl()` override).
- Fixed clicking an already-selected session in the sidebar not bringing its editor tab to focus; left-click now re-triggers `onSessionSelected` even when the row is already highlighted.
- Fixed xterm.js rendering issue where the final frame of interactive prompts (rapid cursor movement + line clearing + redraw) sometimes didn't paint. A debounced `term.refresh()` is now scheduled after writes settle.
