# Version 1.0.0

Released: 2026-07-22

Commit range: `6f5e073..HEAD`

## Major changes

- Removed the **Gemini CLI** agent type. Google discontinued the CLI, so all Gemini support has been dropped: the agent enum entry, settings (enable toggle + command), history reader, hook config, and path resolver code. Existing sessions for other agents are unaffected.

## Major fixes

- Fixed a `NoClassDefFoundError: com.intellij.ui.jcef.JBCefApp` crash when opening the tool window on IntelliJ Platform 2026.2 (build 262+). JCEF classes now live behind a dedicated platform module, so the plugin declares `<depends>com.intellij.modules.jcef</depends>`.
- Fixed historical session resolution for projects whose path contains non-alphanumeric characters (e.g. a directory with a `.` in its name). Agents encode the project cwd by replacing every non-alphanumeric character with `-`, but the resolver only replaced `/`, so the history directory lookup missed. Both the Claude and Cursor path encoders now match the agents' encoding.

## Tooling

- Added a project `.editorconfig` that disables wildcard-import collapsing (aligning IntelliJ's Optimize Imports with ktlint's `no-wildcard-imports` rule) and expanded all existing wildcard imports.
