# Version 0.9.1

Released: 2026-06-14

Commit range: `8172b73..6f5e073`

## Major changes

- Added project-scoped settings under **Settings → Tools → Agent CLI → Project**, backed by a new project-level `AgentCliProjectSettings` service stored in the project's workspace file (machine-local, not shared via VCS).
- Added a **Project args** field for the Sandbox agent: extra arguments substituted into the sandbox command's `{project_args}` placeholder for that project only (e.g. `--overlay my-project`). If the placeholder is absent, the args are appended to the command.
- `AgentCommandBuilder` now takes a `Project` instead of a raw path so it can resolve the per-project sandbox args when building launch and resume commands.

- None.
