# Version 0.8.1

Released: 2026-05-05

Commit range: `af883d3..ab02adc`

## Major changes

- Added an **Always resume historical sessions in code editor** setting. When enabled, double-clicking a session in the history sidebar resumes it as an editor tab instead of in the tool window; the right-click menu then offers **Open in Plugin View** as the override. The existing **Return to plugin view** link on editor tabs always moves a session back to the tool window regardless of this setting.
- Added a custom monochrome robot icon (same as the tool window icon) next to the filename on editor tabs hosting an agent session, via a new `AgentCliSessionFileIconProvider`.

- None.
