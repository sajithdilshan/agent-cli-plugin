# Version 0.7.0

Released: 2026-04-27

Commit range: `d1f031f..9fe67fa`

## Major changes

- Added attention notifications: when an agent needs input (permission prompts, idle confirmations, Codex permission requests), the session row shows a red dot instead of the green play icon and an IDE balloon fires. Opt-in hook installation merges idempotently into Claude, Gemini, and Codex config files with `.bak` backups and clean uninstall.
- Added Windows support for the notification hooks via a PowerShell `notify.ps1` script, with platform-aware script resolution in `HookInstaller`.
- Added an "Enable flow control" setting so users can opt out of PTY watermark throttling. When disabled, writes stream without ack/pause/resume coordination.
- Reworked the hook installer settings UI with a richer preview that groups entries by agent.

## Major fixes

- Fixed session-close leaks by forcibly destroying the PTY process (`destroyForcibly`) instead of a polite `destroy`, ensuring agent processes don't linger after a session is closed.
- Fixed cross-platform session path handling: `SessionPathResolver` now normalizes `\` to `/`, strips trailing slashes, and lowercases Windows drive letters so Codex / Claude / Gemini session lookups work on Windows filesystems.
- Updated the bundled xterm.js assets and added CSS overrides for xterm 6.0's VS Code-style scroll shadows and hardcoded `#000` viewport background, preventing visual artifacts in the padded terminal view.
