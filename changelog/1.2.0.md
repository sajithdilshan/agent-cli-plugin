# Version 1.2.0

Released: 2026-11-01

Commit range: `a4ea17d..HEAD`

## Major fixes

- Claude Code session history now shows the first prompt the user actually typed. Newer Claude Code versions write slash commands (`/model`, `/effort`, …), local-command caveats/output and other injected entries as `user` records at the top of the session log; these are now skipped (`isMeta` entries and known system tags). Sessions that contain only commands fall back to the first command, e.g. `/review 123`.
