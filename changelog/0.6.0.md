# Version 0.6.0

Released: 2026-04-14

Commit range: `9d35fdd..28e77c6`

## Major changes

- Added terminal flow control with a watermark-based `TerminalFlowController` that prevents xterm.js write buffer from growing unbounded during fast output bursts, with comprehensive test coverage.
- Sessions now auto-close when the agent process exits, replacing the previous manual shell invocation approach with direct command execution.
- Improved resource cleanup by properly registering disposables for the sidebar and PTY bridges, removing component listeners on dispose, and joining reader threads during shutdown.

## Major fixes

- Fixed character encoding issues in the terminal by ensuring proper UTF-8 locale handling.
- Fixed URL opening from the terminal so that links are correctly intercepted and opened in the browser.
- Refactored loading screen handling in the terminal page HTML.
- Added changelogs for prior versions.
